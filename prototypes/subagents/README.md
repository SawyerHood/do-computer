# Sub-agents: a mock-up

`index.html` is the click-through the sub-agents in the web app were built from. It is one file
with no build step: open it in a browser. Everything in it is pretend.

A sub-agent is a conversation the agent starts and keeps running while it stays free to talk. Each
has its own chat, which can be opened from the chat it was started in, from the agent's panel, and
from the chat list. Its chat is read and not written in: only the agent talks to its sub-agents.
The strip along the bottom switches between the scenes and is not part of the design.
