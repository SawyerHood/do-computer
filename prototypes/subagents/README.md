# Sub-agents: a mock-up

`index.html` is a click-through of how background subagents could look in the web app. It is one
file with no build step: open it in a browser. Everything in it is pretend, and none of it is
built.

A sub-agent is a conversation the agent starts and keeps running while it stays free to talk. Each
has its own chat, which can be opened from the chat it was started in, from the agent's panel, and
from the chat list. You can message one directly, and the agent is told what you said. The strip
along the bottom switches between the scenes and is not part of the design.
