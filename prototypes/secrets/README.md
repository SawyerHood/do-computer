# Saved passwords: a mock-up

What the first pull request of `PLAN-agent-secrets.md` would put on screen: a Dood signs in with
a password it never sees, kept in Do Computer's own store. It is drawn before any of it was
built. It is not part of the app and nothing here is imported by it. Everything in it is pretend.

It was built on 2026-10-13 as drawn (HANDOFF.md, section 5, item 81). Where the app differs:
the settings window's own way out is in the corner the mock-up gave "Add a login", so that
button sits under the page's opening words; a row's menu says "Change its name or sites"; and
the accent is the open Dood's own color.

`index.html` is one page with no build step; open it from the file system. It needs the network
once, for the Geist typeface. The switch at the top right changes light and dark. Nothing in
the pictures answers a click.

**In the chat:**

1. A Dood asks for a login: the form above the message box, where it asks for an API key today,
   with the site taken from the page the Dood is on.
2. It asks before using one: the card the app already shows for anything set to Ask first.
3. What the chat keeps: one line, the site and the username.
4. The wrong site: nothing is typed, and the Dood is told why.

**In settings:**

5. A workspace's passwords: a fourth page beside People, Computers and Models.

Not drawn: the form "Add a login" opens (the form of picture 1 with a name), the row in a
Dood's Permissions, and the phone app.
