# Documents in the library: a mock-up

`index.html` is the click-through the library's file tree and viewers were built from. It is one
file with no build step: open it in a browser. Everything in it is pretend, including the files.

It has one thing the app does not: the agent's writing appearing as it types. In the app a
document changes when the agent's tool call ends. The strip along the bottom switches between
the scenes and is not part of the design.
