# Documents in the library: a mock-up

`index.html` is the click-through the library's file tree and viewers were built from. It is one
file with no build step: open it in a browser. Everything in it is pretend, including the files.

It has two things the app does not have yet: a document opening beside the chat, in the place
of the agent's panel, and the agent's writing appearing as it types. The strip along the bottom
switches between the scenes and is not part of the design.
