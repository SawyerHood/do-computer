set one up, start with [the self-hosting guide](../self-hosting.md).

- [Configuration](configuration.md): every environment variable
- [Computers](computers.md): the kinds of machine a Dood can work on, and what each keeps
- [Models](models.md): the deployment's models, a workspace's own, and what is paid by whom
- [Security and trust](security.md): what a Dood can reach, and what limits it
- [Saved passwords and cards](passwords.md): how a Dood signs in and pays without seeing a password or a card's number, and who has them
- [What a Dood can do](agents.md)
- [Teams](teams.md)

- [Apps](apps.md): how the Composio connector works

- [Notifications](notifications.md), and the app on a phone's home screen
- [Desktop app](desktop.md)
- [Mobile app](mobile.md)

These pages are read here on GitHub. A guide is different: it is a Markdown file directly in
[`docs/`](..), and every deployment serves it under `/docs`, as a page for people and as the
file itself (the same address with `.md` after it) for agents. Adding a file there adds it to
the site, and its pictures go in `docs/images`.
