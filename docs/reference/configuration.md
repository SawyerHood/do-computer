# Configuration

| Variable                                   | Meaning                                                                                                                                                                                                                                                          |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OPENROUTER_API_KEY`                       | Pays for every call to the deployment's own models. A workspace signed in to a provider of its own pays for those. See [Models](models.md).                                                                                                                      |
| `DC_DEFAULT_MODEL`                         | Model new Doods start on unless their owner chose one: `provider/model` or an OpenRouter id. Default `anthropic/claude-haiku-5.5`, or the first of `DC_MODELS`.                                                                                                  |
| `DC_MODELS`                                | The only models the deployment itself offers, comma-separated: `provider/model` or OpenRouter ids. Default: all it can run. See [Models](models.md).                                                                                                             |
| `DC_ADMIN_EMAILS`                          | Comma-separated emails of those who may sign the deployment itself in to model providers, for everyone. See [Models](models.md).                                                                                                                                 |
| `DC_BASE_URL`                              | Public origin, for example `https://agent.example.com`. Needed behind a proxy and for sign-in with Google or GitHub.                                                                                                                                             |
| `DC_AUTH_SECRET`                           | Signs sessions. Required on Cloudflare; on Node one is generated and kept in the data directory.                                                                                                                                                                 |
| `DC_SIGNUP`                                | `invite` (default), `waitlist` or `open`. With `invite`, the first account needs no invitation; after that only `DC_ALLOWED_EMAILS` and people invited to a team can sign up. With `waitlist` anyone can, and waits: see [Doods and the waiting list](doods.md). |
| `DC_ALLOWED_EMAILS`                        | Comma-separated emails allowed to sign up.                                                                                                                                                                                                                       |
| `DC_LANDING`                               | `1` shows the landing page at `/` to whoever is not signed in; without it `/` leads to the sign-in form. It says "coming soon" where sign-up is by invitation.                                                                                                   |
| `RESEND_API_KEY`, `DC_EMAIL_FROM`          | Send team invitations by email through [Resend](https://resend.com), from that address. Without both, an invitation is a link to pass on.                                                                                                                        |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | Enable sign-in with Google. The OAuth client is a web application whose redirect address is `<DC_BASE_URL>/api/auth/callback/google`.                                                                                                                            |
| `DC_PASSWORD_SIGNIN`                       | `off` takes away sign-in with an email and a password, for new accounts and for those that have one, leaving Google and GitHub. It does nothing where neither of those is set up. The mobile app signs in with a password only.                                  |
| `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET` | Enable sign-in with GitHub. The OAuth app's callback address is `<DC_BASE_URL>/api/auth/callback/github`.                                                                                                                                                        |
| `DC_TRANSCRIPTION_MODEL`                   | OpenRouter speech-to-text model for dictation. Default `openai/whisper-large-v3`.                                                                                                                                                                                |
| `DC_SEARCH_MODEL`                          | OpenRouter model that reads web search results for the Dood. Default `anthropic/claude-haiku-4.5`.                                                                                                                                                               |
| `DC_JUDGE_MODEL`                           | OpenRouter model asked whether a Dood meant to stop, when it ends on a progress update. Default `mistralai/mistral-small-3.2-24b-instruct`.                                                                                                                      |
| `DC_REVIEW_MODEL`                          | OpenRouter model that notes where each chat stands, for the Dood's other chats. Default: the model that reads web search results.                                                                                                                                |
| `DC_SANDBOX`                               | The kind of machine a workspace is given: `just-bash` (default), `daytona`, `modal`, `cloudflare` or `none`. See [Computers](computers.md).                                                                                                                      |
| `DC_SANDBOX_KINDS`                         | The kinds of machine on offer, comma-separated. Default: every kind that has what it needs.                                                                                                                                                                      |
| `DC_SANDBOX_NETWORK`                       | `off` gives Doods' computers no internet access, whichever kind they are. On by default.                                                                                                                                                                         |
| `DC_ALLOW_PRIVATE_HOSTS`                   | `1` lets connectors, skill installs and the built-in computer reach this machine and private networks, and use plain http.                                                                                                                                       |
| `DC_DATA_DIR`, `PORT`, `HOST`              | Node only.                                                                                                                                                                                                                                                       |
