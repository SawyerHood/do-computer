# AGENTS.md

## pi-durable

Whenever you are unsure how to use `@earendil-works/pi-durable` (or the other pi packages), clone
https://github.com/earendil-works/pi and read its source and examples before guessing:

```sh
git clone --depth 1 https://github.com/earendil-works/pi /tmp/pi
```

The durable package is `packages/durable`; examples are in `packages/*/examples` (for example
`packages/agent/examples` and `packages/coding-agent/examples`).
