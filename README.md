# durable-computer

An open-source, self-hostable, always-on personal agent. Each agent has a name, an avatar, a
personality, memory and its own computer. It keeps working when the client is closed, runs
schedules, learns skills, and can reach your own machines.

One codebase deploys to Cloudflare Workers and to plain Node. Models are called through OpenRouter.

**Status:** early development. See [PLAN.md](./PLAN.md) for the design and build order.
